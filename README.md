# 🖥️ <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/dot-net/dot-net-original.svg" width="30" height="30"/> Empleados & Departamentos - WinForms App

Aplicación de escritorio para gestión de empleados y departamentos desarrollada con Windows Forms para Desarrollo en C# del TEC Mayor (.NET Framework) y MySQL.

## 📋 Características Principales
- **Gestión CRUD** completa de empleados y departamentos
- **Interfaz intuitiva** con botones de acción centralizados
- **Validación de datos** (RUT, códigos de 4 dígitos, etc.)
- **Relación Empleado-Departamento** integrada
- **DataGridView optimizado** para visualización de datos

## 🛠️ Tecnologías Utilizadas
| Componente       | Tecnología           |
|------------------|----------------------|
| Frontend         | Windows Forms (.NET) |
| Backend          | C#                   |
| Base de Datos    | MySQL                |
| ORM              | MySqlConnector       |
